# إعلان أوكسيرا التفاعلي | OxCira

إعلان تفاعلي بهيئة جوال: «هذا الجوال يخفي فرصة… والفرصة تنتظر من يردّ».
يضغط الزائر «ابدأ التجربة»، فتصله إشعارات أوكسيرا، ثم مكالمة من «الفرصة التالية» بتسجيل عربي ونص متزامن، ثم يستكشف الجوال: السوق، رحلة المادة، الرسائل، الصور، الملاحظات، الملفات، وقنوات التواصل الرسمية.

الإصدار 2.2 — 26 نوفمبر 2026. HTML وCSS وJavaScript فقط، دون إطار عمل أو عملية بناء أو قاعدة بيانات.

## محتويات المشروع

```
index.html        الصفحة
style.css         التصميم (الجوال والكمبيوتر)
app.js            منطق التجربة: الحالة، المكالمة، الصوت، التطبيقات، الروابط
config.js         كل النصوص والروابط وإعدادات الصوت (عدّل من هنا)
assets/           الشعار، الصور، النغمة، التسجيلات، الخطوط، بطاقة الاتصال
.nojekyll         يمنع GitHub Pages من معالجة الملفات
README.md         هذا الملف
TESTING.md        تقرير الاختبار
SOURCES.md        المصادر، وما استُبعد، والتعارضات، والنواقص
RECORDING_SCRIPT.md  نص التسجيل الصوتي الجديد وطريقة تركيبه
```

## النشر على GitHub Pages

1. فك ضغط ملف ZIP.
2. ارفع **محتويات** المجلد (وليس ملف ZIP) إلى جذر المستودع، بحيث يكون `index.html` في الجذر ومعه مجلد `assets` و`.nojekyll`.
   - من واجهة GitHub: Add file ← Upload files، ثم اسحب الملفات والمجلدات، ثم Commit.
   - ملاحظة: ملف `.nojekyll` مخفي في بعض الأنظمة؛ تأكد من رفعه.
3. افتح Settings ← Pages.
4. في Build and deployment اختر Deploy from a branch، ثم الفرع `main` والمجلد `/ (root)`، واحفظ.
5. انتظر دقيقة أو اثنتين، ثم افتح الرابط الذي يظهر أعلى صفحة Pages (مثل `https://ersmartskill.github.io/oxcira/`).

كل المسارات نسبية، فالموقع يعمل داخل مستودع فرعي دون تعديل.
بعد أي تحديث، إن ظهرت النسخة القديمة فحدّث الصفحة مع تجاوز الذاكرة المؤقتة، أو غيّر رقم `?v=2` في `index.html`.

## التعديل عبر config.js

| ما تريد تغييره | المفتاح في config.js |
|---|---|
| الروابط (الموقع، السوق، Linktree، الحسابات) | `links` |
| رقم واتساب والرسالة الجاهزة | `links.whatsappNumber` و`links.whatsappMessage` |
| البريد وموضوعه ونصه | `links.email` و`links.emailSubject` و`links.emailBody` |
| نصوص الافتتاح والمتصل والتنبيه | `story` |
| موعد وصول الاتصال ومدة الرنين | `story.callDelayMs` و`story.ringTimeoutMs` |
| النغمة ومقاطع التسجيل والنص المعروض لكل مقطع | `audio.ringtone` و`audio.clips` |
| فئات المواد وأنواع الشراء | `materials` و`dealTypes` |
| صور الألبوم ووصفها | `photos` |
| الملفات العامة القابلة للتنزيل | `publicFiles` |
| شكل الأرقام في الساعة | `locale.digits` (`latn` أو `arab`) |

### تغيير التسجيل الصوتي
اتبع `RECORDING_SCRIPT.md`: سجّل المقاطع الخمسة، ضعها في `assets/`، ثم فعّل قائمة «التسجيل الجديد» في `config.js`. التجربة تنتقل للمقطع التالي عند انتهاء المقطع فعليًا، فلا حاجة لضبط أي مدة.

### الملفات والملاحظات
- ملف التعريف مضاف في `publicFiles` (فتح وتنزيل). لإضافة ملف آخر ضعه في `assets/` وأضف عنصرًا مماثلًا. لا تضف مقترح روشن أو أي وثيقة داخلية.
- الملاحظات الجاهزة في `notes`. لكل ملاحظة `id` ثابت؛ الملاحظة الجديدة بمعرّف جديد تظهر حتى للزوار السابقين، والمحذوفة لا تعود.

### واتساب
الرابط المختصر في `links.whatsapp` (`https://wa.me/966538127976`). تُرفق رسالة جاهزة فقط في آخر خطوة من «رحلة المادة» لأنها تحمل تفاصيل المادة.

## كيف تعمل الروابط الخارجية
- كل أيقونة خارجية رابط HTML حقيقي (`<a href>`) يُفتح بنقرة المستخدم مباشرة، دون أي انتظار أو مؤقت قبله، ودون iframe.
- واتساب يفتح برابط مختصر، والبريد برسالة جاهزة **لا تُرسل تلقائيًا**.
- إذا لم تغادر الصفحة خلال ثانية ونصف من النقر (أي أن البيئة منعت الفتح غالبًا، كبعض المعاينات داخل التطبيقات)، تظهر نافذة بدائل: «فتح القناة»، «فتح في الصفحة الحالية»، «نسخ الرابط»، مع الرابط ظاهرًا وقابلًا للتحديد والنسخ يدويًا.
- لا تدّعي الصفحة نجاح الفتح أبدًا. عند فتح قناة خارجية يتوقف الرنين والتعليق، وتؤجَّل المكالمة حتى العودة.
- كل الروابط موجودة أيضًا للنسخ في تطبيق «الإعدادات».

## الخصوصية
لا تُرسل الصفحة أي بيانات. الملاحظات والإعدادات تُحفظ في متصفح الزائر فقط (localStorage)، ولا توجد مفاتيح API أو خدمات مدفوعة.
